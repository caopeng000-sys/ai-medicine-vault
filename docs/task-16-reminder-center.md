# 任务 16：提醒中心

## 背景

项目已经具备药品管理、病历记录、过敏记录和就医准备能力，但提醒信息分散在不同页面。为了让家庭健康资料更适合日常使用，本轮新增独立提醒中心，把需要优先处理的事项集中展示。

## 本轮目标

- 汇总药品过期、库存不足和即将过期提醒。
- 汇总病历中的复诊时间提醒。
- 汇总中等及严重过敏风险。
- 按优先级排序，让用户先看到更紧急的事项。
- 不引入生产环境依赖，不修改数据库结构。

## 实现范围

新增统一提醒计算模块：

- `features/medicine-vault/health-reminders.ts`

新增提醒中心页面：

- `app/reminders/page.tsx`

更新侧边栏导航：

- `components/medicine-vault/app-shell.tsx`

新增单元测试：

- `features/medicine-vault/health-reminders.test.ts`

## 提醒规则

药品提醒复用现有药品状态规则：

- 已过期：高优先级
- 库存不足：中优先级
- 即将过期：低优先级

复诊提醒规则：

- 复诊日期已过：高优先级
- 3 天内复诊：中优先级
- 14 天内复诊：低优先级

过敏风险规则：

- 严重过敏：高优先级
- 中等过敏：中优先级
- 轻微过敏：暂不进入提醒中心

## 结果

提醒中心现在可以作为首页之外的待处理事项入口，集中查看药品、复诊和过敏三类风险。每条提醒都带有成员、类型、优先级、说明和跳转入口，便于回到对应业务页面继续处理。

## 后续可扩展

- 增加按成员、提醒类型和优先级筛选。
- 增加提醒处理状态，例如已查看、已处理、稍后提醒。
- 增加用药提醒和复诊提醒的日历化展示。
- 后续接入通知服务后，可把提醒推送到邮件、短信或移动端。
