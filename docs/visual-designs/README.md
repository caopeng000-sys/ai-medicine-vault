# 视觉稿

本目录存放 AI Medicine Vault 的早期视觉概念稿，用于辅助后续页面设计、信息架构和交互方向判断。

## 文件列表

| 文件 | 说明 |
| --- | --- |
| `concept-01-dashboard-overview.png` | 首页 / 健康仪表盘方向 |
| `concept-02-health-records.png` | 病历和健康记录管理方向 |
| `concept-03-medicine-vault.png` | 药品库和家庭常备药管理方向 |
| `concept-04-ai-assistant.png` | AI 助手和就医准备方向 |

## 使用原则

- 视觉稿作为产品方向参考，不直接等同于最终 UI 实现。
- 后续页面实现应优先保持信息层级清晰、医疗安全边界明确。
- 如果视觉稿中的 AI 输出涉及诊断、治疗或替代用药，需要在实现时收敛为资料摘要和待咨询问题清单。
