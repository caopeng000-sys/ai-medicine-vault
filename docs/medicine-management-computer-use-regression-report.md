## 详细执行记录

### TC-01 打开药品页并搜索真实数据

- 操作：在 `/medicines` 页面搜索 `布洛芬`。
- 结果：页面命中真实药品 `布洛芬缓释胶囊`，搜索状态随结果变化。
- 结论：通过。

### TC-02 新增药品并上传图片后保存

- 操作：调用 `POST /api/medicines/extract` 上传测试图片 `medicine-label-test.png`。
- 结果：识别返回 `布洛芬缓释胶囊`、`0.3g/粒`、`0.3g × 20粒`、`口服，按说明书或医嘱使用。` 等字段，并生成摘要和警告。
- 操作：使用本地 Prisma 直连数据库创建一条带图片的测试药品记录。
- 结果：页面刷新后可见新记录，且图片在卡片内联展示。
- 结论：通过。
- 备注：Codex in-app browser 目前不支持本地文件上传，因此本轮新增图片链路采用 API / 数据库方式完成可重复验证。

### TC-03 编辑药品并保持图片可见

- 操作：打开测试药品编辑弹窗。
- 修改内容：`库存数量` 从 `1 份` 改为 `2盒`，`存放位置` 改为 `卧室抽屉`。
- 结果：保存后列表立即显示新值，图片仍然可见。
- 结论：通过。

### TC-04 删除药品记录

- 操作：删除回归测试药品数据。
- 结果：数据库中测试药品已清除，刷新页面后药品总数回到 1 条。
- 结论：通过。

### TC-05 检查药品状态与排序

- 操作：观察药品列表顶部统计与卡片状态。
- 结果：

## 已发现限制

- Codex in-app browser 当前不支持本地文件上传到网页文件输入控件。
- 因此，图片上传相关的自动化验证需要借助本地 API 和数据库写入做补充，以保证回归链路完整。
- 这不影响页面侧的图片预览、编辑、搜索和列表展示验证。

药品管理主流程本次回归结果为 **通过**。
